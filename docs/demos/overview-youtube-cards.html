Beesharp

Overview Card Concepts · YouTube Rhythm + Outline Icons

Inspired by the YouTube mobile feed: full-bleed top visual stage, floating corner pill & circular toggles, thin bottom-edge progress/outcome scrubber, clean bold title, avatar + two-line meta with hollow ▷ counter, and monochrome outline icon actions. Every number, bar, step, and icon is clickable.

Icon stroke:
EXAMPLE 01

Stage & Scrubber Card (Closest to YouTube Feed)

The top 16:8 stage is the live/finished bee bar chart. Top-right circular buttons toggle "Errors only" or "Slow line" right on the card; lower-left subtitle box calls out the top failure step; the bottom-edge scrubber summarizes success/slow/failed proportions (or live progress).

EXAMPLE 02

Editorial KPI Stage (SPIEGEL TV Card Inspiration)

High-contrast corner status tag + bold hero figure over a quiet background sparkline and subtle inner frame. Designed for instant room-distance scanning while keeping the exact same clean YouTube footer and outline icon strip.

EXAMPLE 03

Step Pipeline Stage (Scenario Steps · Brain 0056)

Uses the top visual stage for declared scenario steps (e.g. Log in → Search → Cart → Pay). Click any step node to drill directly into bees that failed or slowed down at that step; top-right circular button switches between typical duration and failure counts.

EXAMPLE 04

Compact High-Density Feed (For 8–12+ Scenarios)

A tighter 16:5.6 visual stage that fits 4 cards across on desktop without losing the YouTube card hierarchy, scrubber line, or crisp monochrome outline icons.

ICON STYLE

Monochrome Outline Icon Set

Uniform stroke weight, rounded caps & joins, zero heavy fills — neutral off-white by default, taking Beesharp's semantic colour (red / amber / emerald / blue) only when signalling status. Try switching the stroke weight in the top right.
